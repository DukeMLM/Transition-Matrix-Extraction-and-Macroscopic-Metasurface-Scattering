## 2026-08-07 14:41 EDT — M1 design study

Scope: `retrieval/FAST_FULL_TMATRIX_WHEEL_PROPOSAL.md`, the current `retrieval/results/fastfull/M1_DESIGN_STUDY.md`, its `retrieval/fastfull` implementation, and the M1 gates. The review used the working tree as-is; implementation files were not changed.

### Findings

1. **[P1] The Gate E error estimates treat a documented systematic discrepancy as hundreds of independent noise samples.** `retrieval/fastfull/design.py:234-248` and `retrieval/fastfull/jacobian.py:75-95` whiten every modal-S entry with the same 2.6333e-3 value, so the posterior benefits from stacking all `n_channels^2` rows (576 rows for `small@8`, and more when cells are pooled). But `retrieval/results/REAL_RETRIEVAL.md:269-271` explicitly establishes that this closure residual is dominated by model/systematic error and is not an iid Gaussian noise floor that can be reduced by averaging. The proposal also requires an estimated complex-S covariance and says not to treat all entries as equally accurate. Therefore the reported 5.4%/4.0% global errors and the statement that Gate E is cleared are not acceptance evidence. Keep them as flat-noise sensitivity numbers, or propagate a covariance/systematic-error model before making any Gate E claim.

2. **[P1] “Dominant-block error” and per-coefficient SNR are calculated in an arbitrary eigenspace basis, so they are not physical or invariant.** `retrieval/fastfull/symmetry.py:248-254` obtains the 40 basis matrices from eigenvectors of a degenerate projector. `retrieval/fastfull/jacobian.py:252-269` then declares individual coordinates above 10% of the largest coordinate “dominant.” An orthogonal rotation of the same valid 40-dimensional D4h-reciprocal space leaves the physical T and global Frobenius error unchanged but changes these results: for `small@8`, the reported 1.10% error on 2 dominant coefficients became 4.39–5.26% on 26–37 coefficients over 100 random basis rotations; the count above SNR 10 changed from 2 to 18–32. Define invariant, physically named multipole-block projectors and compute blockwise Frobenius errors/covariances, or remove the dominant-block and per-coordinate acceptance claims.

3. **[P2] The findings round a failed 5% gate into a pass and use the band RMS instead of the measured 8 um value.** `retrieval/results/fastfull/M1_DESIGN_STUDY.md:65` reports 5.4% for `small@8` and requires sigma <= 2.42e-3, below the assumed 2.6333e-3, yet `retrieval/fastfull/M1_FINDINGS.md:36-45` says the method clears a strict “below 5%” target. The unrounded value is 5.4456%. Moreover, `results/fit_sigma_from_closure.npz` gives 2.8417e-3 at the 8 um endpoint; using that frequency-matched value raises the same provisional linear estimate to about 5.9%. Preserve unrounded pass/fail logic and use the frequency-resolved closure spectrum if these sensitivity estimates remain in the report.

4. **[P2] The claimed validation scope exceeds what the tests establish.** `retrieval/fastfull/M1_FINDINGS.md:128-136` says the flux-normalized measurement operator “is correct,” but the strongest gate only reproduces the existing analytic/single-order `sparams_oblique` convention. It does not validate CST multimode port fields, per-mode gauge/labels, reference-plane phases, or a diffractive cell—the same items correctly deferred to M3 in `retrieval/fastfull/README.md`. State that the analytic transform is consistent with the existing single-order model; reserve physical CST multimode correctness for Gate B.

### Algorithm and experiment recommendations

1. **Replace coordinate-level targets with invariant sector/block targets before further optimization.** Construct explicit projectors for the named D4h parity/irrep and multipole-family blocks. From the recovered covariance, report each block's expected squared Frobenius error, worst posterior eigen-direction, and global trace. Optimize the minimum generalized singular value after applying declared physical block scales. This preserves the useful 40-dimensional reduction without allowing an arbitrary eigenspace rotation to change the scientific verdict.

2. **Turn the current flat-noise calculation into a robustness envelope.** Keep iid sigma as an explicitly optimistic sensitivity case, then add (a) the measured frequency-resolved closure spectrum, (b) low-rank/channel-correlated systematic models inferred from closure and reference-plane/mesh sweeps, and (c) a norm-bounded adversarial discrepancy. Rank designs by worst-case invariant block error and de-embedding amplification across these models. A candidate that wins only by averaging nominally independent modal entries should not advance.

3. **Use M2 to compare a small, falsifiable candidate set rather than only refining the current winner.** Carry `small@8` as the cost baseline, `pool-3@8` as the best optimistic-global-error candidate, and `generic@8` as the algebraic correctness reference. Add one geometrically distinct cell/Bloch encoding reserved as a holdout. With independently converged Ewald C, run the same passive D4h ensemble through all candidates, measure nonlinear Jacobian degradation and `cond(I + T_eff C)`, and test C-continuation/multistart recovery without looking at the wheel reference. This directly tells whether pooling buys robust nonlinear information or merely more iid rows.

4. **Change the design objective after C is available.** The next objective should minimize worst-case invariant T error (or maximize its reciprocal) subject to cost, Wood/grazing margins, signal floor, and a de-embedding-condition constraint. `sigma_40` alone is useful for C=0 screening but should become a diagnostic, not the optimizer's final scalar. Preserve a Pareto front for accuracy versus predicted wall time instead of fixing an arbitrary cost-penalty exponent.

5. **Make the first CST work a calibration experiment, not a wheel-result experiment.** Only after the M2 synthetic gate, run the chosen empty cell at multiple mesh levels, both `+k_B` and `-k_B`, and at two reference-plane locations. Export every modal field/label and record factorization versus RHS time. This single experiment should estimate the actual channel covariance/gauge stability and recalibrate the cost model. Advance to the Mie sphere only if the complete empty operator, reciprocity mapping, and de-embedding invariance close.

6. **Treat 20 um as a separate low-response hypothesis test.** The current scale-invariant C=0 search shows that simply resizing the 8 um geometry is insufficient; it does not prove that no design can help. Revisit 20 um only with the calibrated covariance and C-aware objective. If it still fails, test a causal cross-frequency prior with held-out frequencies and report how much information comes from the local 20 um data versus the prior; do not count prior-dominated recovery as independent per-frequency identification.

## 2026-08-07 15:45 EDT — physics-prior direction from `cma_infinite`

Scope: read-only comparison of the current fast-full retrieval and Gate-A artifacts with `DaryLu0v0/cma_infinite` at `main`, commit `f2755fb5be00e8d229a932cf74ea347d4b45d525`. This is an algorithm/research-direction review, not an implementation change.

### Main finding

The 8 um coded-cell inverse is **not algebraically underdetermined in the ideal model**: `small@8` is rank 40/40, its noise-free recovery is exact, and its multistart basin is unique (`retrieval/results/fastfull/GATE_A_STUDY.md:14-24,31-41`). It becomes practically non-identifiable when physical calibration/model-error directions are admitted. At the measured discrepancy, the reference-plane and smooth-angular perturbations produce 24.0% and 19.9% T error, while iid and TE/TM-mixing cases produce about 5.1% and 4.3%. The first physics to add should therefore be a model of the experiment's nuisance physics; stronger shrinkage on T alone would mainly hide calibration bias.

A tangent-space audit makes this sharper. For the current `small@8` Jacobian, 99.981% of the reference-plane tangent norm projects into `col(H)`; only 1.95% of that perturbation is distinguishable from changing T. Constant, `kz/k`, and `(kz/k)^2` smooth-error tangents have projection ratios 0.99990, 0.99981, and 0.99998. The resulting linearized apparent-T changes are 20.0%, 23.9%, and 27.1%, consistent with Gate A. Passivity projection changes the reference-plane case only from 23.99% to 23.64%. Thus passivity is a useful physical constraint, but it is not the main cure for the present ambiguity.

### What `cma_infinite` contributes—and what it does not

`cma_infinite` is not an iterative optimizer or regularized retrieval. Its core is a physics-defined algebraic change of coordinates:

1. pair structured S with a matched empty-cell `S0` at identical reference planes;
2. form the transition operator `(S0^H S - I)/2`;
3. use eigen/SVD spectra plus an **independent null/background repeat** to count resolvable radiating modes;
4. split frequency at changes in propagating Floquet-channel count;
5. track modal subspaces across frequency and verify modal reconstruction.

Relevant source: [`core.py` lines 75–211 and 254–373](https://github.com/DaryLu0v0/cma_infinite/blob/f2755fb5be00e8d229a932cf74ea347d4b45d525/cma_sparam/core.py#L75-L211), [`floquet.py` lines 110–256](https://github.com/DaryLu0v0/cma_infinite/blob/f2755fb5be00e8d229a932cf74ea347d4b45d525/cma_sparam/floquet.py#L110-L256), and the [algorithm/caveats](https://github.com/DaryLu0v0/cma_infinite/blob/f2755fb5be00e8d229a932cf74ea347d4b45d525/README.md#L99-L134).

This machinery is valuable as preprocessing, diagnostics, and initialization, but an eigendecomposition of an already measured complete S is only a coordinate change; it does not increase information rank. The source also states that modes dark to retained propagating Floquet channels are invisible. A modal prior can select values in such null directions, but cannot demonstrate that the data identified them. In addition, the exact orthogonal rank-one expansion and unit-circle relation are lossless results. The Au wheel is lossy, so its isolated spherical scattering operator must be treated as reciprocal and contractive, not projected onto the lossless circle.

### Recommended physics-assisted architecture

1. **Add physical nuisance parameters before regularizing T.** Represent residual reference-plane offsets with the signed-`kz` phase congruence, TE/TM basis uncertainty with per-order 2x2 rotations, and mesh/discretization error with a low-dimensional angular model. Infer their means/covariances from matched empty-cell, reference-plane-shift, mesh-ladder, and Mie calibration runs. In the wheel fit, use those calibrated distributions rather than allowing unconstrained nuisance variables to trade freely against T.

2. **Use the CMA transition operator as an observability front end.** For every cell and constant-channel frequency block, compute the matched-background transition SVD, calibrate radiating rank with an independent empty repeat, and track degenerate D4h subspaces by principal angles rather than arbitrary individual eigenvectors. Use this to weight/initialize the exact `S = W T_eff A` fit. Do not equate a lattice-dressed periodic CMA eigenvector with an isolated-wheel T eigenvector.

3. **Re-express isolated `T0` in explicit D4h parity/irrep blocks after lattice de-embedding.** The ten multiplicity blocks are `[1,2,2,2,4]` for each horizontal parity. Reciprocity makes each block symmetric and gives the current 40 complex coefficients. This sectorization alone improves interpretability but does not reduce degrees of freedom.

4. **Add a sectorwise passive causal modal model across frequency.** A practical target is a reciprocal bounded-real/state-space or temporal-coupled-mode realization with a small number of resonances per irrep, nonnegative absorptive damping, shared poles over a subband, and factored low-rank residues. Schematically,

   `T_s(w) = T_bg,s(w) + sum_q rho_sq(w) g_sq g_sq^T`,

   with the causal negative-frequency partners and passivity enforced on `S_sph = I + 2 T0`. The normalization must be gated in the repository's VSWF convention before use. The gain comes from sharing poles and coupling vectors across frequency—not from diagonalizing each frequency separately. The current model uses `80 * N_frequency` real unknowns; a Q-mode sector model scales approximately as `sum_s Q_s (2 + 2 n_s) + N_background` real parameters over the whole subband if complex coupling vectors are required.

5. **Keep a complete-space escape term:** `T = T_phys(theta) + DeltaT_40`. `DeltaT_40` remains in the full D4h-reciprocal space with invariant, multipole-scaled hierarchical shrinkage. This exposes missing poles, high-order content, or imperfect templates rather than silently redefining “full T” to mean only the chosen characteristic modes. Geometry-derived ring/spoke current templates may initialize the modal vectors, but they must be frozen from independent physics or training folds; learning them from the same S data adds their degrees of freedom back.

6. **Optimize the coded cell against nuisance-marginalized information.** With whitened T and nuisance Jacobians `J = [H G]`, use the Schur complement

   `F_T = H^H H + Q_T - H^H G (G^H G + Q_eta)^-1 G^H H`

   and maximize its weakest declared physical direction at matched cost/SNR. Publish the likelihood-only spectrum (`Q_T = 0`) separately, because the prior changes posterior uncertainty but does not change measurement rank. This directly rewards encodings that distinguish T from reference-plane and angular-systematic tangents—the failure observed in Gate A.

7. **Use a staged inner solve, not a single larger black box.** Retain the current `C=0` seed and `C -> eta C` continuation; then add calibrated nuisance MAP refinement, ramp the passive/multipole prior, fit shared poles by variable projection over a short subband, and finally release `DeltaT_40`. Validate after every stage on a held-out cell and held-out frequencies.

### Smallest discriminating ablation

Run the same blind targets and structured perturbations through:

| branch | change | what it tests |
|---|---|---|
| A | current 40-complex-per-frequency recovery | baseline |
| B | A + empty-calibrated reference-plane/angular nuisance model | whether calibration removes the dominant alias |
| C | B + passivity only | whether passivity adds value beyond calibration |
| D | C + D4h-sector shared poles/subspaces | whether cross-frequency modal physics adds real information |
| E | D + complete `DeltaT_40` residual | whether the reduced modal model is misspecified |

Use both model-matched targets and deliberately misspecified targets with an extra pole, weak higher-order content, slight symmetry breaking, and altered loss. Choose modal rank/pole count only from independent null calibration and training folds. Report free/effective parameter count, likelihood-only singular spectrum after nuisance marginalization, global and per-irrep T error, held-out-cell S error, leave-frequency-out error, passivity/causality residual, pole bootstrap stability, runtime, and sensitivity to `rank +/- 1` and a 2x prior-weight change.

### Stop/go criteria

- **Go to an M3/M4 pilot** only if the physics-assisted branch reduces the current reference-plane-class error below 5%, keeps dominant-block error below 2%, predicts a distinct held-out cell below the independently measured complex-S discrepancy, and remains stable under pole-count/prior-weight ablations and misspecified targets—not only targets generated by the same prior.
- Require the Mie sphere's supported diagonal modes to about 1%, zeros at the numerical floor, and cell-independent recovery before applying the model to the wheel.
- **Stop and redesign the encoding/calibration** if the nuisance-marginalized weakest direction remains inadequate. Stronger T shrinkage is not a substitute for separating nearly collinear T and calibration tangents.
- If held-out S passes but weak T blocks move materially with prior strength or have low data-resolution eigenvalues, publish two artifacts: **data-identified T** and **physics-completed T**. The latter is a useful conditional model, but it is not an independently identified full T-matrix.

### Verdict

The proposed direction is worthwhile, but the highest-value physics prior is not yet a characteristic-mode truncation. First make the dominant reference-plane and mesh systematics explicit and design the measurement to separate them from T. Then add a D4h-sector, passive, shared-pole modal model across frequency, with a full-space residual and strict held-out validation. This can materially reduce variance and band-level parameter count while preserving an honest boundary between measured information and physics-supplied completion.

It is then evaluated only for one newly drawn reference-plane perturbation, through the same exact `W-T-A/C` forward model, in one direction; it does not test the other error families, an independent modeling discrepancy, or Gate E's reverse-role recovery. Preserve this cell as consumed development data. Rename the present result accordingly. M3 must estimate physical nuisance distributions and complex channel covariance from reference-plane shifts, mesh ladders, empty-cell repeats, and port-field repeats, then rerun both fixed-physical-parameter and fixed-output-RMS studies.

4. **[P1] The label/gauge test excludes the campaign's known failure and Gate A's permutation requirement.** `mode_mixing` is only a common real TE/TM congruence `M S M^T`; it cannot represent the earlier receive-only TM-row sign fault (`retrieval/RESULTS.md:99-104`). Consequently the claim that label/gauge error is the least damaging class is unsupported. Add exact invariance/recovery under a consistently permuted channel map, explicit detection/failure under one wrong map, and calibrated independent input/output phase, sign, and overlap perturbations.

5. **[P2] Gate A's ensemble, basin, and uncertainty requirements remain open.** The control is one exactly-D4h passive draw tested only with `small@8`; the other candidates use one reference wheel and three stochastic trials. “Every seed” is also too broad: the published run uses two starts formed by multiplicatively perturbing the same linear seed, so zero/small coordinates and distant passive basins are not explored. Test all candidates on a deterministic passive-D4h ensemble spanning sector weights, loss, norm, and `cond(I-CT)`; add zero, additive full-space, random-passive, norm-scaled, and continuation seeds; publish paired quantiles/confidence intervals and covariance coverage. Predeclare physical sectors/scales rather than choosing the “dominant” block from the hidden truth.

6. **[P2] The holdout statistic mixes incompatible scales.** The report divides `max |dS|` over 576 entries by a quantity used as per-entry RMS. From the stored values, holdout RMS is 0.752 sigma (`small@8`), 1.658 (`generic@8`), and 0.780 (`pool-3@8`), whereas the displayed maxima are 1.65, 3.68, and 1.62 sigma. Neither is a calibrated physical acceptance statistic with the current transplanted scalar sigma. Report covariance-whitened RMS/chi-square and a familywise-calibrated maximum against independently measured per-channel covariance. 7. **[P2] The current artifact and prose have smaller provenance/reporting mismatches.** `fit_sigma_from_closure.npz` predates the current writer schema and lacks `sigma_channels` and `sigma_rms`; the current M1 prose says five multistart seeds although the artifact used two, and its control D4h residual differs from the regenerated report. ### Result-driven algorithm and experiment recommendations

- **First discriminating physics experiment:** estimate a nuisance Jacobian `G` and covariance from matched empty-cell reference-plane shifts, a mesh ladder, and repeated port-field/channel-map exports. Compare `small@8`, `generic@8`, and fixed-cost pooled designs using the nuisance-marginalized Fisher/Schur spectrum, not independently normalized perturbations.
